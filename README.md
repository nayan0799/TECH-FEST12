# MIND RIZZ

An animated black-and-white event website, student portal, and organizer control room.

## Stack

- Next.js App Router
- TypeScript
- React
- Supabase Auth
- Supabase PostgreSQL
- Supabase Storage
- Vercel

---

# Start locally

Install Node.js 22 LTS and npm.

Open a terminal inside the `mind-rizz` folder:

```bash
npm install
npm run dev
